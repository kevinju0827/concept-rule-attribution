# 0008. 差異量採用以一步變化量正規化的歐氏距離，確認性指標只使用排序

- 狀態：已接受
- 日期：2026-10-02

## 背景

神經網路的歸因估計，是同一個表示配上實際動作與配上什麼都不做時，兩個下一步預測之間的差異。世界模型的規格要求，差異量的選擇必須寫成決策紀錄，因為它決定了歸因估計的數值代表什麼。

若表示是機率分布，可以使用 KL 散度。本專案考慮的世界模型，表示都是單一向量，KL 散度無法使用。

不同模型、不同亂數種子學出的表示，尺度各不相同，未經處理的距離無法互相比較。

考慮過的選項：

- 歐氏距離。最直接，但受尺度影響。
- 餘弦距離。不受長度影響，但兩個方向相同、長度不同的預測會被視為相同。
- 先白化表示再計算距離。消除各方向的尺度差異，但需要估計共變異數，維度高時不穩定。
- 以一步變化量正規化的歐氏距離。

## 決策

神經網路歸因的純量估計定義為：

```
差異量 = ‖預測_實際 − 預測_不作為‖ / m
```

其中 `‖·‖` 為歐氏距離，`m` 為訓練資料中相鄰兩步單張畫面表示之間歐氏距離的中位數，每個訓練好的模型各計算一次。數值的意義是「相當於幾個典型的一步變化」。

所有確認性的指標，例如曲線下面積與等級相關，都只依賴估計值的排序。正規化不會改變排序，所以這項選擇不會影響確認性的結論，只影響報告中數值的可讀性。

另以讀取器把兩個預測各自讀成明確的狀態，再比較兩者的差異，作為結構化的神經網路歸因。它是讀取的結果，不是差異量，與純量估計並列回報。

## 影響

歐氏距離對每個維度一視同仁。表示若在某些方向上變異特別大，距離會被這些方向主導。訓練目標中若有把表示推向等向分布的約束，這個問題較小；對沒有這種約束的模型，以白化後的距離作為探索性比較。

需要二元判斷時，例如列出混淆矩陣，必須在驗證資料上選定門檻。這類結果只作為描述，不作為確認性的主張。
