# 0014. 規則以結構正確與保真度–複雜度評估，以描述長度選擇

- 狀態：已接受
- 日期：2026-10-02

## 背景

本專案的研究目的之一，是檢驗從畫面學出的表示空間能否不經語言抽出規則，最終目標是具備強的概念與邏輯能力的模型。規則抽取的流程是：以線性讀取器把表示讀成明確的狀態，在讀出的狀態上搜尋「條件 → 效果」形式的規則，組成一個可執行的狀態轉移函式。

當時的判定方式是：搜尋時，候選規則只要重現它所涵蓋的訓練紀錄中至少比例 q 的部分就保留，q 依讀取準確率設定；判定時，在保留資料的真實狀態上，一條規則必須精確重現它涵蓋的每一筆轉移才算正確，不接受「大致吻合」。

對這個方式提出的質疑是：生物並沒有精確的預判能力，往往只做到夠用的程度，卻已經具備優於目前神經網路的概念與邏輯能力，所以「精確」不是必要條件。這個質疑有實證支持：人對物理場景的直覺判斷，可以由帶雜訊的近似模擬解釋（Battaglia、Hamrick 與 Tenenbaum，2013）；人的認知可以理解為在有限的計算資源下取捨準確度（Lieder 與 Griffiths，2020）。

討論後的結論是區分兩種「精確」：

- **數值的精確**：預測的細節與數量有多準。生物在這方面確實粗略，它不是必要條件。
- **結構的正確**：條件與效果的組成是否對。例如「後面被擋就推不動」，小孩不知道箱子會滑多遠，但這條規則的結構是對的；嬰兒對物體恆存、不可穿透等的預期也是類別式的（Spelke 與 Kinzler，2007）。推廣與組合能力來自結構正確，而不是數值精確。

此外，精確的數量概念在人類身上要靠數詞這類符號工具（Frank、Everett、Fedorenko 與 Gibson，2008），這表示離散、精確的結構可能正是強邏輯能力的來源之一。因此不應放棄量測結構是否完全正確，但不應把「逐筆精確重現」當成唯一的判定。

原本的方式還有兩個問題：q 是一個只能憑經驗設定的門檻；而「只接受完全正確的規則」會把結構正確但有少量例外的規則與完全錯誤的規則一起判為失敗，丟掉兩者之間的所有資訊。

## 決策

**規則語言。** 規則為「條件 → 效果」：條件是以代理或物體為參考點的命題的合取，效果是對狀態的一組具型別的修改。允許兩種擴充：

- 帶例外的規則：規則在它涵蓋的紀錄中有一部分不成立，例外的比例明確記錄。
- 帶機率結果的規則：同一條件下有多個可能的效果，各附機率，用於帶雜訊的環境。

狀態中某個變數不存在時（例如某些環境變體沒有能量），以它為對象的命題視為成立，以它為對象的效果不適用。這是規則語言對「多個機制如何組合」所做的假設：同一個互動的前提條件取合取，效果取聯集。

**以描述長度選擇規則集。** 以固定的編碼計算規則集本身的位元數，加上在它之下編碼資料所需的位元數（例外，或帶機率結果時的負對數似然），兩者之和最小的規則集被選中。比較在驗證資料上進行。這取代容忍比例 q：讀取錯誤造成的少量例外，只要規則仍能大幅壓縮資料就會被保留。

**回報保真度–複雜度曲線。** 對不同的複雜度上限，回報能達到的最佳保真度。保真度在確定性環境中是下一步狀態完全正確的比例，在帶雜訊的環境中是平均對數似然。環境真正的規則以相同的語言編碼，在圖上標為一個參考點。

**結構正確性仍以精確判定。** 對環境規則表中的每一條規則：在保留資料的真實狀態上、該規則適用的所有轉移中，抽出的函式都輸出正確的結果，才算這條規則的結構被找回；帶機率結果時，條件與可能結果的集合必須完全正確，機率則以與真實機率的差距另外回報。這是「完全正確」那一端的量測，不是唯一的判定。

**沿用的部分。**

- 搜尋只使用讀出的狀態，不接觸任何真實狀態；真實狀態只用於事後的判定。
- 判定以行為為準：兩個函式在所有保留資料上的輸出相同就視為相同，不比較程式碼的文字。
- 函式中「先代理、後環境」或「先環境、後代理」的組合順序，以訓練資料上的描述長度選擇。
- 把相同流程直接套用在真實狀態上，作為上限對照。
- 同一個函式另外套用到讀出的狀態，量測端到端的結果。

## 影響

研究問題從「能否抽出精確規則」改為「能否抽出結構正確、可組合的規則」。精確仍被量測，但從通過的唯一條件，變成一條曲線的一端。

描述長度依賴編碼方式的選擇；編碼方式必須在門檻鎖定時寫定，之後不得為了讓結果好看而更改。

「缺席的命題視為成立、效果取聯集」是一個先驗假設。本專案的環境依這個方式建構，所以它在這裡成立；在組合方式不同的環境中，例如兩個機制只要其中一個允許就成立，這個假設會失敗，那時需要讓組合方式本身也成為搜尋的對象。

帶機率結果的規則，需要足夠多的紀錄才能估計機率；覆蓋率檢查須涵蓋帶雜訊的環境變體。
