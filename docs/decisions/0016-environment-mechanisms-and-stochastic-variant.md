# 0016. 客製環境以確定性版本為主，規則依機制分組可關閉，並在第四階段加入帶雜訊的變體

- 狀態：已接受
- 日期：2026-10-02

## 背景

本專案在 MiniGrid 上自建環境，必要要素為：環境自身的動態、屬於其他物體的隱藏變數、屬於代理自身的隱藏變數、條件式規則、可切換的看不見的時間規則、預防事件。

閱讀 MiniGrid 3.1.0 原始碼時發現的限制，至今仍然成立：

- 內建的 `DynamicObstaclesEnv` 在代理動作之前、以拒絕取樣移動障礙物。同一步內代理不可能擋下障礙物；之後不同動作的分支抽亂數的次數不同，障礙物會因為亂數錯開而走向不同位置，這個差異來自實作，不是因果。
- RGB 畫面預設帶有代理視野的陰影，許多格子的外觀隨代理的位置與朝向改變。
- 格子圖片以物體的編碼為快取鍵，同一物體的不同外觀若編碼相同，會回傳舊圖片。
- 撿起與放下在沒有可撿物體的環境中等同「什麼都不做」。
- 隱藏變數若沒有可見的後果，或它的值無法由觀測歷史決定，讀取失敗就無法判讀。

原本的環境設計只有確定性的動態，並把帶雜訊的情況留到本專案之後。後來的討論改變了兩件事：

- 研究目的不是要求數值上的精確預測，而是結構正確、在數值上「夠用」的規則。只有在帶雜訊的世界中，「夠用的規則」與「精確的規則」才真正分得開；純確定性的環境無法檢驗這一點。
- 需要檢驗分別學到的規則疊加時是否仍然適用，這要求環境的規則能依機制分組、整組關閉，而不改變其餘規則。

## 決策

**物體與規則。**

- 箱子：代理向前走進箱子時推動它，後方完全空著才成功；有隱藏的耐久度，初始值固定，被「作用」擊中時減一，下一張畫面以實心外觀短暫提示，歸零時消失。
- 巡邏球：沿行進方向每步前進一格，被擋時反轉方向留在原地。行進方向不畫在畫面上。
- 充電格：只有代理能站上去，代理在步末位於其上時能量回到上限。
- 代理的隱藏變數：能量，推動與擊中成功時各消耗一，為 0 時兩者無效；推動冷卻，推動成功後的固定步數內再推無效。

每一步依序處理代理的動作、巡邏球、計時器、充電。代理先動，預防事件可以在一步之內發生。

動作為五個：左轉、右轉、前進、作用、什麼都不做。

**機制。** 規則分成四個機制，每個機制可以整體關閉：

| 機制 | 包含 | 關閉時 |
| --- | --- | --- |
| 箱子 | 箱子、耐久度、推動、擊中 | 不放箱子 |
| 能量 | 能量、充電格、互動的能量條件與消耗 | 沒有能量變數與充電格，互動不受能量限制也不消耗能量 |
| 冷卻 | 冷卻變數、推動冷卻的條件與設定 | 沒有冷卻變數 |
| 巡邏球 | 球、行進方向 | 不放球 |

多個機制作用於同一個互動時，前提條件取合取，效果取聯集。關閉某個機制，只移除它貢獻的條件與效果，其餘機制的規則完全不變。冷卻機制的開關，就是可切換的時間規則。

**確定性的版本為主。** 第零到第三階段，以及第四階段的分級推廣、規則開關與三方比對，都使用確定性的版本：亂數只在回合開始時用來產生初始狀態。

**帶雜訊的變體用於第四階段。** 加入兩種雜訊：巡邏球每步以固定機率隨機改變行進方向；推動在條件都成立時，以固定機率滑脫而沒有效果。每一步在處理任何規則之前，從回合的雜訊產生器抽出固定數量的亂數（每個球位各兩個、推動一個），與動作和狀態無關，不論是否用到。複製環境時雜訊產生器一併複製，因此不同動作的分支共用相同的外在雜訊。雜訊機率設為 0 時，變體必須與確定性版本完全相同。

**帶雜訊時的標準答案分兩種。**

- 實現的標準答案：共用外在雜訊時，實際分支與什麼都不做分支的差異。
- 期望的標準答案：對下一步所有可能的雜訊結果取期望，各變數在兩個分支中不同的機率。

神經網路的預測不知道雜訊的實際值，它的歸因與期望的標準答案比較；實現的標準答案作為次要的比較。

**其他沿用的規定。** 繪圖時關閉視野陰影；隱藏變數不得影響畫面中的任何像素；同一物體的不同外觀必須反映在它的編碼中。每個隱藏變數都必須有可見的後果，且它在每一步的值能由回合開始以來的畫面與動作歷史算出；環境記錄每個隱藏變數是否可識別，以及決定它的事件距今幾步。

## 影響

帶雜訊的變體與機制組合的檢驗各需要一套資料與一組世界模型，計算成本增加。

雜訊抽取的方式固定為「每步固定數量、與動作和狀態無關」，這讓反事實分支的差異只來自因果，但也意味著改變雜訊的種類或數量時，必須重新產生該變體的全部資料。

機制之間的組合方式（條件取合取、效果取聯集）是這個環境的設計，不是自然界的定律。結果只能說明在這種組合方式下發生了什麼。

規則中的數值，例如能量上限、冷卻步數、耐久度、雜訊機率、回合長度、物體數量，在資料覆蓋率的試驗前只是起始值。
