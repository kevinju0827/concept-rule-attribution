# 0017. 所有機率輸出都量測校準，以適當評分規則為主，不作為通過條件

- 狀態：已接受
- 日期：2026-10-02

## 背景

本專案有三處輸出機率：

- 線性讀取器對每個目標輸出各類別的機率。
- 帶例外或帶機率結果的規則，對每個條件給出各結果的機率。
- 結構化的歸因估計，可以表示為「某個變數因代理而改變」的機率。

原本只量測準確率與描述長度，沒有量測這些機率本身是否可信：說 0.8 的時候，是否真的約有八成正確。讀成狀態時又直接取機率最高的類別，機率的資訊在這一步就被丟掉。一個準確率高但機率不可信的讀取器，會讓規則搜尋與歸因無從知道哪些讀取結果可以相信。

已知的事實：

- 現代神經網路的機率常常過度自信（Guo、Pleiss、Sun 與 Weinberger，2017）。
- 輸入分布偏移時，校準通常隨之變差（Ovadia 等，2019）。本專案的分級推廣測試正是一系列分布偏移。
- 以分箱計算的期望校準誤差會低估真正的校準誤差，分箱越少低估越多（Kumar、Liang 與 Ma，2019）。
- 負對數似然與 Brier 分數是嚴格適當的評分規則（Gneiting 與 Raftery，2007），不需要分箱，同時反映校準與區辨能力。本專案以描述長度選擇規則集，而描述長度中資料的部分就是負對數似然。

另一個相關的問題：讀取器與規則都只能從事先定義的類別中選一個，沒有「不知道」這個選項。機率低的時候它們仍然會給出答案。

## 決策

**所有機率輸出都回報校準。** 指標分兩級：

- 主要：負對數似然與 Brier 分數。兩者都不需要分箱。
- 描述：可靠度圖，以及以等數量分箱計算的最高類別期望校準誤差。分箱數在門檻鎖定時寫定；報告中註明分箱估計會低估。

**帶雜訊的變體直接與真實機率比較。** 環境知道每個結果的真實機率，所以規則與歸因給出的機率，直接與真實機率比較平均絕對誤差，不需要分箱，也不必從結果反推。

**分級推廣測試的每一級都回報校準**，用來檢查讀取器在陌生畫面上是否變得過度自信。

**結構化神經網路歸因的機率。** 實際與什麼都不做兩個預測各自讀成每個變數的機率分布，「變數 v 改變」的機率定義為一減去兩個分布在相同值上的機率乘積之和。這假設兩個讀取結果彼此獨立，是近似。

**使用原始機率。** 確認性分析不做事後的重新校準，因為要量測的是模型本身。以驗證資料做溫度縮放後的結果，只作為探索性比較。

**校準不作為通過條件。** 研究問題關心的是結構是否正確、歸因是否一致；校準關心的是機率能否被信任。把它加入通過條件，會增加多重比較的負擔，卻不直接回答研究問題。已經是確認性指標的超額對數損失維持不變。

**讀成狀態時仍取機率最高的類別**，但每個目標的機率向量一併保存，供校準與探索性分析使用。

**探索性的選擇性預測分析。** 回報讀取器的風險–涵蓋率曲線：只在信心高於門檻時給出答案，錯誤率如何隨涵蓋率變化（Geifman 與 El-Yaniv，2017）。另比較一種結合設定：規則所讀取的變數，讀取信心都高於門檻時才使用規則，否則使用神經網路。

## 影響

每項讀取、規則與歸因的報告多了校準的欄位，但不增加確認性比較的數目。

結構化神經網路歸因的機率依賴獨立性的近似；兩個預測來自同一個歷史條件表示，實際上相關，所以這個機率只作為描述。

選擇性預測與信心閘控是探索性的。若它們顯示出明顯的好處，要納入確認性分析時必須另寫紀錄，並在新的門檻鎖定中事先寫定。
