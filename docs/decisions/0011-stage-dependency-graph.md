# 0011. 階段依相依關係推進，神經網路歸因的檢驗不等待規則抽取

- 狀態：已接受
- 日期：2026-10-02

## 背景

原本的階段是一條直線：第零到第四階段依序執行，任一階段未通過就停止。神經網路歸因與標準答案的比對放在第四階段，排在規則抽取之後。

神經網路歸因只需要訓練好的世界模型，以及第一階段確認過的表示，不需要規則。先前的決策已經指出，規則抽取失敗時，神經網路估計是可用的退路；但在直線的安排下，規則抽取一失敗，第四階段就不會執行，退路恰好在需要它的時候無法使用。

同樣地，規則搜尋方法在真實狀態上的上限對照，只需要環境與資料，不需要世界模型。

先前的決策也沒有決定，資源有限時兩個研究目標的優先順序。

## 決策

各項檢驗依實際的相依關係排列：

- 第零階段：世界模型的工具確認，以及環境與資料的驗收。
- 第一階段：概念是否形成。依賴第零階段。
- 神經網路歸因的檢驗：與標準答案比對。依賴第一階段。
- 第二階段：動作在表示空間中的轉換。依賴第一階段。
- 規則搜尋的上限對照：依賴第零階段的環境與資料驗收，可與第一階段並行。
- 第三階段：從表示空間抽出規則。依賴第二階段與上限對照。
- 第四階段的推廣測試與規則開關的成對比較：依賴第三階段。
- 第四階段的三方歸因比對：依賴第三階段與神經網路歸因的檢驗。

停止規則改為逐條路徑適用：一項檢驗未通過，只擋住依賴它的檢驗，不影響其他路徑。仍然不得以擴大規模或改用更複雜的環境繞過未通過的檢驗。

資源有限時，神經網路歸因的檢驗優先於第二、三階段。它是本專案的核心機制，成本也較低。

## 影響

即使規則抽取失敗，本專案仍能回答「神經網路的反事實歸因與標準答案是否一致」，研究問題三不會整個落空。

並行的路徑多了，需要追蹤的狀態也多了。每項檢驗的進入條件與結果都必須明確記錄。

階段的編號維持原樣，以免與既有文件的用語衝突；神經網路歸因的檢驗不佔用新的編號。
