# 0004. 以規則模擬作為第二個歸因估計，規則解釋不了的變化不直接歸給代理

- 狀態：已接受
- 日期：2026-10-02

## 背景

本專案有兩個研究目標：從表示空間抽出精確規則，以及估計環境變化中有多少是代理自己造成的。原本的歸因估計只有一種：預測器在實際動作與「什麼都不做」下產生兩個預測，以兩者的差作為估計。這個估計是一個數值，無法逐項檢查它代表什麼。

提出的觀察是：若能從表示空間抽出精確規則，就能確認哪些變化是規則導致的，進而確認哪些變化是代理自己造成的。

這個觀察有一個需要處理的問題。把「規則解釋不了的變化」直接當作「代理造成的變化」，會把三種來源混在一起：沒有抽完整的動作規則、規則沒有涵蓋的其他來源（例如沒被抽到的環境動態或看不見的變數），以及規則本身的誤差。在只有單一代理、環境規則完整時，這個混淆不大；一旦加入其他行動者，第二種來源會大幅增加，錯誤地歸給代理的部分也會跟著增加。

## 決策

把抽出的規則分成兩類：從「什麼都不做」時的狀態轉移抽出的環境自身規則，以及描述每個動作效果的動作規則。以抽出的狀態轉移函式分別模擬實際動作與「什麼都不做」，兩個結果的差作為第二個歸因估計。

規則解釋不了的剩餘變化，不直接歸給代理。只有在相同情境下改變代理的動作、剩餘部分隨之改變時，才歸為代理造成；其餘以「無法歸因」回報。

神經網路估計、規則估計與複製環境得到的標準答案，三者在每一步都記錄並比對。

## 影響

規則估計依賴規則抽取成功，所以它在第三階段之後才能使用；第三階段之前，只有神經網路估計可用。規則抽取失敗時，神經網路估計仍是可用的退路。

多了一個可讀的估計，三方比對可以在兩種估計不一致時，指出是哪一方出錯，這是只有單一估計時做不到的。

「以改變自己的動作來確認剩餘變化的來源」需要在相同情境下嘗試不同動作。在本專案中，這可以靠複製環境直接做到；在不能複製環境的 Minecraft 中，需要另外設計。

兩種歸因估計都不加入訓練目標，避免代理被引導去盡量影響世界，而不是準確估計自己的影響。
