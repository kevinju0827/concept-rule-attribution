# 0015. 推廣測試加入機制組合，畫面大小固定，容量對照分成兩組

- 狀態：已接受
- 日期：2026-10-02

## 背景

本專案比較抽出的規則與神經網路，哪一個更能推廣到沒看過的情況。比較的設定包括：神經網路預測器；抽出的規則；兩者結合（規則涵蓋時用規則，否則用神經網路）；以及排除替代解釋的對照組。所有設定都以同一組讀取器把預測讀成明確的狀態後比較。

推廣測試的設計有四個問題。

**更大的格子量到的是輸入大小，不是規則。** 編碼器的輸入大小固定；讀取器的目標逐格定義在固定的畫面上，訓練時沒出現過的位置沒有對應的類別。格子變大時失敗，無法分辨是規則沒學到，還是輸入與讀取器根本無法處理。

**在單一環境中，條件組合無法乾淨地保留。** 資料由隨機動作產生，條件組合由互動自然出現；要讓某個組合在訓練資料中完全不出現，只能修改環境的動態，而那會改變要學的規則本身。

**沒有檢驗多條規則疊加時是否仍然適用。** 複雜環境中的規則會同時作用、互相限制。以一條條獨立規則描述世界，在符號人工智慧中已知擴展得很差：要寫明什麼不會改變的框架問題、間接效果的衍生問題、條件永遠列不完的限定問題（McCarthy 與 Hayes，1969）。若規則只能在學到它們的情境中使用，遇到新的組合就失效，那它們對複雜環境沒有價值。這是推廣測試中最該回答、卻沒有被檢驗的問題。物件導向世界模型的研究也把組合推廣視為核心問題（Zhao、Kong、Walters 與 Wong，2022）。

**容量對照沒有排除它要排除的解釋。** 原本的對照是「參數量對齊結合設定的較大神經網路」。規則沒有可訓練的參數，結合設定的參數量就等於基準神經網路，所以這個對照實際上與基準一樣大。結合設定若勝出，替代解釋不只是參數變多，還有「兩個元件加上切換」本身帶來的好處。

## 決策

**畫面大小固定。** 分級推廣測試的偏離方向為外觀（箱子使用沒見過的顏色；箱子與球的顏色互換）、數量（更多箱子與球）、布局（沒見過的內部牆面形狀），每個方向兩級，加上與訓練分布相同的第零級。不測試更大的格子。

**單一環境中的條件組合，改為依訓練頻率分層。** 依每種條件組合在訓練資料中出現的次數分層回報。

**新增機制組合的檢驗。** 把環境的規則依機制分組，每個機制可以整體關閉，關閉時它的物體、變數與規則都不存在，其餘機制的規則不變。另訓練一組世界模型，訓練資料只來自幾個各含部分機制的環境變體，使某些機制在訓練中從未同時出現；測試時使用這些機制同時出現的變體。第一級為兩個從未同時出現的機制，第二級為所有機制。

在完整環境上訓練的同一設定，以相同的測試資料評估，作為「看過這些組合」的參考。組合代價定義為參考的表現減去只看過部分機制時的表現。規則與神經網路的比較以組合代價為準。

機制組合的檢驗不改變任何規則，只改變哪些規則在訓練中同時出現，因此能乾淨地回答「分別學到的規則疊加時是否仍然適用」。規則語言對組合方式的假設是：同一個互動的前提條件取合取，效果取聯集；這個檢驗同時檢驗了這個假設。

**容量對照分成兩組。**

- 同閘控的雙網路：與結合設定使用完全相同的切換條件，但規則的部分換成第二個以相同資料訓練的神經網路。排除「兩個元件加上切換」的解釋。
- 加倍參數的單一網路：參數量為基準神經網路的兩倍。排除「只是多了參數」的解釋。

**加入讀取不出錯的上限設定。** 把抽出的規則直接套用到真實狀態，分辨失敗出在讀取還是規則。

## 影響

不再檢驗對更大格子的推廣，這需要能處理可變大小輸入的編碼器與不依賴固定位置的讀取方式，留待之後的工作。

機制組合的檢驗需要另一組世界模型，以及這組模型的讀取器與規則抽取；兩組容量對照也需要額外的訓練。計算成本因此明顯增加，在路線圖中另列。

訓練變體的設計決定了哪些組合是新的。變體與測試組合在環境規格中寫定，並在門檻鎖定前固定。
