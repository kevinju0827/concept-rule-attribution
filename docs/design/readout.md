# 讀取

以線性讀取器把表示轉成明確的狀態，並以介入檢查確認模型確實使用這些資訊。第一階段以它判斷概念是否形成；規則抽取、結構化的神經網路歸因與第四階段的比較，都以它把表示轉成 `State`。

讀取目標與對照方式的理由記錄在 [decisions/0009](../decisions/0009-probe-targets-and-controls.md)；兩種表示的區分記錄在 [decisions/0007](../decisions/0007-frame-and-history-representations.md)。

## 讀取目標

外圈的牆固定不變，不列為目標。「逐格」指內部 6×6 的每一格。

| 類別 | 目標 | 程式碼名稱 | 判定所用的表示 | 只在這些位置評分 |
| --- | --- | --- | --- | --- |
| 逐格 | 物體種類 | `cell_type` | `z_t`、`b_t` | 全部 |
| 逐格 | 物體顏色 | `cell_color` | `z_t`、`b_t` | 有物體的格子 |
| 逐格 | 受擊提示 | `hit_cue` | `z_t`、`b_t` | 有箱子的格子 |
| 姿態 | 代理位置 | `agent_pos` | `z_t`、`b_t` | 全部 |
| 姿態 | 代理朝向 | `agent_dir` | `z_t`、`b_t` | 全部 |
| 相對 | 前方一格的物體種類 | `front_type` | `z_t`、`b_t` | 全部 |
| 相對 | 前方第二格的物體種類（含「格子外」） | `front2_type` | `z_t`、`b_t` | 全部 |
| 自身隱藏 | 能量 | `energy` | `b_t` | 可識別的時間點 |
| 自身隱藏 | 推動冷卻 | `cooldown` | `b_t` | 可識別的時間點，且時間規則開啟 |
| 他者隱藏 | 耐久度 | `durability` | `b_t` | 有箱子且可識別的格子 |
| 動態 | 球的行進方向 | `heading` | `b_t` | 有球且可識別的格子 |

可見與相對的目標在兩種表示上都讀取並回報。隱藏與動態的目標只以 `b_t` 的結果作為判定依據；它們在 `z_t` 與像素上的結果用於洩漏檢查。

第一階段關於「概念形成」的主要主張落在相對、隱藏、動態三類。可見的逐格與姿態目標從原始像素就能線性讀出，它們的結果只作為健全性檢查。

## 表示的來源

| 來源 | 角色 |
| --- | --- |
| 訓練後的 `z_t`、`b_t` | 被檢驗的對象 |
| 未經訓練、相同架構的 `z_t`、`b_t` | 必須勝過的基準，每個訓練種子配一個相同種子的未訓練模型 |
| 原始像素 | 參考值：這個變數是否本來就能從輸入以線性方式讀出 |
| 真實的可見狀態 | 單張畫面上限：見下文 |

### 單張畫面上限

隱藏變數雖然不畫在畫面上，但可能與畫面上看得到的東西相關。例如代理站在充電格上時，能量必然是上限。所以隱藏變數在單張畫面上的讀取結果，合理的參考不是隨機猜測，而是「只知道此刻看得到的一切時，最多能猜得多準」。

單張畫面上限的計算方式：以標準答案中此刻的可見狀態（逐格內容、顏色、提示、代理姿態）為輸入，訓練一個不限於線性的分類器（例如梯度提升樹）預測該隱藏變數，在保留資料上的準確率即為上限。它使用真實狀態，所以是單張畫面資訊所能達到的上限，而不是某個模型的結果。

- **洩漏檢查**：隱藏與動態目標在原始像素與 `z_t` 上的讀取結果，不得超過單張畫面上限。超過代表畫面洩漏了隱藏變數，必須先修正環境。
- **概念主張**：隱藏與動態目標在 `b_t` 上的讀取結果必須超過單張畫面上限，才能說明模型整合了歷史。

## 讀取器

- 多項邏輯斯迴歸。輸入以 `train` 分割的平均與標準差標準化。
- L2 正則化強度在 `val` 分割上從固定的候選值中選擇。
- 每個目標各自獨立；逐格目標以一個線性層實作，每一格有自己的權重。
- 在 `train` 分割上訓練，在 `test` 與 `ood` 分割上評分。訓練樣本數在門檻鎖定時寫定。

確認性的分析只使用線性讀取器。非線性的讀取器只作為探索性分析，用來區分「資訊不存在」與「資訊存在但不是線性的」。

## 指標

- 準確率與各類別平均的 F1。逐格目標取各格的平均，另回報 36 格全部正確的比例。
- 線上編碼的描述長度（Voita 與 Titov，2020）：把訓練資料依 0.1%、0.2%、0.4% … 100% 的比例分塊，每一塊以前面所有塊訓練出的讀取器編碼，總編碼長度越短，代表表示越容易讀出這個變數。以「均勻編碼長度 ÷ 線上編碼長度」回報壓縮比。
- 與基準的差：每個種子的訓練後結果減去同種子未訓練模型的結果。
- 隱藏變數另外回報準確率隨記憶年齡的變化。

## 對照與健全性檢查

- **未經訓練的模型**：所有指標都與它比較。
- **原始像素**：參考值，不是必須勝過的對象。
- **打亂標籤**：以打亂後的標籤訓練相同的讀取器，在保留資料上的結果必須落在隨機猜測的範圍內，否則代表流程中有資料洩漏。它不衡量表示或讀取器的能力。
- **洩漏檢查**：見上文的單張畫面上限。

## 介入檢查

讀取器能讀出變數，只證明資訊存在。介入檢查確認模型在預測時確實使用這個資訊。

**方法。**

1. 選定一個時間點、一個目標變數與一個新值。在 `b_t`（隱藏與動態目標）或 `z_t`（可見與相對目標）上，沿著讀取器中「新值的權重減去目前值的權重」的方向移動，找出使讀取器以事先寫定的差距改判為新值的最小移動量。
2. 以修改後的表示預測下一步：修改 `b_t` 時直接接上轉移頭；修改 `z_t` 時先重算 `b_t`。以讀取器把預測讀成 `State`。
3. 建立對應的真實狀態：把該時間點的 `State` 中的目標變數改成新值，以真正的環境規則從它執行同一個動作，得到預期的下一步。不合法的修改（例如把外牆改成空格）不納入。
4. 只在「受這次修改影響的變數」上比較：也就是從原狀態與從修改後狀態出發，真正的下一步中不同的那些變數。

**對照。** 沿著長度相同的隨機方向移動，計算同樣的指標。

**指標。** 介入成功率：讀出的預測在受影響的變數上全部與預期相符的比例。與隨機方向及未修改時的比例比較。

**優先檢驗的介入。**

| 目標 | 修改 | 預期的後果 |
| --- | --- | --- |
| `front_type` | 牆 ↔ 空 | 前進時代理是否移動 |
| `energy` | 0 ↔ 大於 0 | 推動與作用是否生效 |
| `cooldown` | 0 ↔ 大於 0 | 推動是否生效 |
| `durability` | 1 ↔ 2 | 作用後箱子是否消失 |
| `heading` | 反向 | 球的下一個位置 |

## 讀成 State

規則抽取與第四階段的比較，需要把表示轉成完整的 `State`：

- 可見與相對的部分以 `z_t` 的讀取器讀出；隱藏與動態的部分以 `b_t` 的讀取器讀出。
- 對預測的下一步：可見部分以 `z_t` 的讀取器讀取 `ẑ_{t+1}`；隱藏部分先以 `ẑ_{t+1}` 與 `a_t` 更新信念，得到 `b̂_{t+1}`，再以 `b_t` 的讀取器讀取。
- 各目標直接取機率最高的類別，不做任何事後修正。讀出的 `State` 彼此矛盾的比例，例如代理位置落在牆上，另外回報。
- 每次讀成 `State` 都一併記錄各目標的讀取準確率，因為讀取錯誤會直接變成規則或歸因的錯誤。
