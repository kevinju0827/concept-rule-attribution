# 環境

代理看到什麼、能做什麼、標準答案從哪裡來，以及硬體能負擔多少。

## 模擬器

MiniGrid，由 Farama Foundation 維護的格子世界套件，以 `pip install minigrid` 安裝。本文件中所有已確認的行為，均以 3.1.0 版為準。

選擇它而非 Minecraft 或自行從頭撰寫的理由，記錄在 [decisions/0002](../decisions/0002-minigrid-as-environment.md)。

## 觀測

模型的輸入只有畫面，不接觸任何文字或符號。

- 以 `FullyObsWrapper` 提供完整視野。MiniGrid 預設只讓代理看到身邊的局部範圍，若不改為完整視野，看不見的狀態會和沒學到的狀態混在一起，第一階段的檢查無法判讀。
- 以 `RGBImgObsWrapper` 輸出 RGB 畫面。畫面大小等於格子邊長乘以每格像素數；8x8 格子、每格 8 像素時輸出為 64x64x3（已確認）。
- 格子大小與每格像素數在第零階段量測顯示記憶體用量後才決定，目前以 64x64 為起點。

## 標準答案

標準答案直接從環境物件的內部狀態讀取：格子內容、代理的位置與朝向、攜帶的物品，以及客製環境新增的屬性。MiniGrid 另有 `SymbolicObsWrapper` 可輸出符號化觀測，但隱藏變數依定義不會出現在任何觀測中，因此一律從環境物件讀取，不經觀測包裝器。

標準答案只用於評估與規則驗證，絕不作為模型的輸入。

## 動作空間

離散動作，必須包含一個嚴格意義的「什麼都不做」動作：執行後除了步數之外，任何狀態都不改變。它必須以一個數值輸入模型，理由見 [world-model.md](world-model.md)。

MiniGrid 3.1.0 中的已確認行為：

- 基礎類別的 `done` 動作不改變任何狀態，但會讓步數加一。
- `GoToDoorEnv` 與 `GoToObjectEnv` 把 `done` 用來結束回合，不能當作「什麼都不做」。
- `DynamicObstaclesEnv` 把動作空間限制為左轉、右轉、前進三種。

因此客製環境必須：保留完整的動作空間；讓 `done` 維持不改變狀態、不結束回合；並在每次修改動作或規則後，重新確認這一點。「什麼都不做」的意義一旦改變，歸因估計所衡量的東西也會跟著悄悄改變。

## 客製環境必須具備的要素

以 MiniGrid 官方的自建環境方式撰寫。以下要素各自支撐至少一項評估，具體形式尚未決定。

1. **環境自身的動態。** 不受代理影響也會發生的變化，例如會移動的障礙物。沒有它，「環境自己造成的變化」與「代理造成的變化」無從區分。
2. **屬於其他物體的隱藏變數。** 不畫在畫面上、只透過間接線索呈現的屬性，例如物體的耐久度，被推或被撞時以短暫的顏色變化表現。
3. **屬於代理自身的隱藏變數。** 例如隨動作消耗的能量，不畫在畫面上。它與上一項分開評估，用來檢驗代理是否同時表示自身與他者的隱藏狀態。
4. **條件式規則。** 例如前方有阻擋時推動無效。用來檢驗規則在表示空間中是否依情境切換。
5. **可切換的看不見的時間規則。** 例如推動後若干步內再次推動無效。從畫面上看不出這條規則，必須透過改變自己的動作時機才能發現。這條規則必須能在不改變其他任何東西的情況下開關，第四階段的成對比較依賴它。
6. **預防事件。** 本來會發生、因代理的動作而沒有發生的事件，例如代理擋住路徑，使移動的物體無法抵達某格。

以下要素在第四階段之後才需要：規則參數在訓練中途改變，例如時間規則的步數，用來檢驗代理追蹤的是變化中的因果關係，還是記住了固定的關係。

## 反事實標準答案

以 `copy.deepcopy` 複製當下的環境，對原本與複本分別執行實際動作與「什麼都不做」，兩者結果的差異就是這個動作造成的精確影響。複製包含亂數狀態，因此會移動的物體在兩個分支中行為一致。已在 `DynamicObstaclesEnv` 上確認：複製後執行相同動作，得到完全相同的下一個畫面。

預防事件的標準答案以同樣方式取得：在「什麼都不做」的分支中發生、但在實際分支中沒有發生的事件，就是被代理阻止的事件。

## 資料

第一到第三階段使用離線紀錄，由隨機動作產生，不訓練策略。每個動作以相同機率抽樣，「什麼都不做」因此自然出現；它的實際比例記錄為參數。

每一步需要保存：畫面、動作、完整的真實狀態（含隱藏變數）、反事實分支的結果、各規則開關的狀態。儲存格式尚未決定，要求是數百萬步的紀錄可以在不整份載入記憶體的情況下讀取。

## 硬體

目標硬體為單張 8 GB 顯示記憶體的 GPU，顯示記憶體是主要限制。

MiniGrid 本身以 CPU 執行、繪圖成本低，顯示記憶體幾乎全部可留給世界模型。
