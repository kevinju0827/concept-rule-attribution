# 世界模型

把畫面壓縮成表示、並在表示空間中預測下一步的模型。後續所有檢查都在它產生的表示空間上進行。

## 組成

- **編碼器**：把一張畫面轉成一個表示。
- **預測器**：根據目前的表示與動作，預測下一步的表示。

預測只在表示空間中進行，不還原成畫面。

## 必要條件

### 「什麼都不做」必須是一個數值

動作以數值輸入預測器，「什麼都不做」是動作空間中的一個值，與其他動作走相同的輸入路徑。不得以移除、遮蔽或歸零動作輸入來代替。

兩種做法回答的是不同的問題。輸入明確的「什麼都不做」，問的是「如果我什麼都不做，下一步會是什麼」，這是介入，答案與代理平常的行為無關。移除動作輸入，問的是「不知道我做了什麼的情況下，下一步會是什麼」，答案是依代理平常行為加權的平均。後者會隨代理行為的改變而漂移，不是反事實。

### 不得發生表示崩塌

表示崩塌指模型把所有輸入都壓成幾乎相同的表示，使預測永遠正確卻沒有學到任何東西。採用的訓練方法必須在設計上防止這件事，並在訓練過程中監看表示的分散程度。

## 差異量

歸因估計需要衡量兩個預測之間的差異。若表示是機率分布，可以使用 KL 散度；若表示是單一向量，KL 散度無法直接使用，需要改用距離類的量。

候選：

- 表示空間中的歐氏距離。
- 以「平均每一步的表示變化量」正規化後的距離，讓數值在不同模型間可比較。

尚未決定。決定時須寫成決策紀錄，因為它決定了歸因估計數值的意義。

## 診斷

以下兩項不是由設計保證的，實作後必須檢查：

- 代理實際執行「什麼都不做」時，歸因估計應接近零。
- 代理的任何動作都無法影響觀測對象時，例如距離太遠，歸因估計應接近零。
