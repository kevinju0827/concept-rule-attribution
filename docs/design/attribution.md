# 歸因

回答「這個變化有多少是我造成的」。本專案以兩種方式估計，並與環境提供的標準答案比對。

## 神經網路的歸因估計

從同一個目前表示出發，產生兩個下一步的預測，兩者的差異就是歸因估計：

```
預測_實際     = 預測器(目前表示, 實際動作)
預測_不作為   = 預測器(目前表示, 什麼都不做)
神經網路歸因  = 差異量(預測_實際, 預測_不作為)
```

「什麼都不做」必須以數值輸入，差異量的衡量方式尚未決定，兩者都規定在 [world-model.md](world-model.md)。

## 規則模擬的歸因估計

以 [rule-extraction.md](rule-extraction.md) 抽出的狀態轉移函式，從同一個讀出的狀態出發，分別模擬實際動作與「什麼都不做」，兩個結果在各項狀態上的差異，就是規則歸因估計。

這個估計以明確的狀態表示，例如「這一步讓某物體的耐久度減少 1」，可以逐項閱讀與檢查。

## 標準答案

依 [environment.md](environment.md) 的方式複製環境，分別執行實際動作與「什麼都不做」，兩個分支的真實狀態差異就是標準答案。

## 規則解釋不了的變化

實際觀察到的變化，扣除規則能解釋的部分後的剩餘，**不得直接算作代理造成的**。剩餘部分混合三種來源：

1. 沒有抽完整的動作規則，也就是確實由代理造成、但規則沒涵蓋的部分。
2. 規則沒有涵蓋的其他來源，例如沒被抽到的環境自身動態，或看不見的變數。
3. 規則本身的誤差。

區分方式是主動改變自己的動作：在相同情境下改變動作，剩餘部分跟著改變的，才歸為第一種。其餘以「無法歸因」回報，不分配給任何來源。

在單一代理、環境規則完整的條件下，這三種來源可以分開。日後加入其他行動者時，第二種來源會大幅增加，這項規定在那時最為關鍵。

## 三方比對

每一步記錄神經網路估計、規則估計與標準答案。比對方式與通過條件在 [evaluation.md](evaluation.md)。

三者一致，表示兩種估計都抓到了真實的因果；不一致時，與標準答案比對可以指出是哪一種估計出錯。

## 不作為獎勵

兩種歸因估計都不加入訓練目標。以高歸因作為獎勵，會讓代理傾向盡量影響世界，這和準確估計自己的影響是不同的目標。
