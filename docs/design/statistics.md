# 統計與報告

所有檢驗共用的統計方法、門檻鎖定程序與結果報告格式。方法的理由記錄在 [decisions/0010](../decisions/0010-statistics-and-threshold-locking.md)。

## 試驗與確認

每個階段分成兩段：

1. **試驗**：使用試驗用的種子與 `pilot` 分割。量測基準線、估計變異、選擇超參數、調整環境參數，並據此設定門檻。
2. **確認**：使用另一組種子與 `train`、`val`、`test`、`ood` 分割，執行事先寫定的分析。

試驗用的種子與資料不再用於確認性的結果。確認性的執行開始後，不再調整任何會影響結果的設定。

## 種子

- 每個確認性的設定至少 5 組訓練種子。試驗顯示變異較大時，以事先寫定的最小效果量、八成的檢定力估計所需的種子數，取兩者中較大者。
- 每個設定的種子編號相同，比較時依種子編號配對。
- 資料以固定的產生器種子產生一次，各訓練種子共用。另以第二個產生器種子產生一套資料，對主要檢驗重做一次，作為探索性的穩健性檢查。
- 未經訓練的對照模型，與訓練後的模型使用相同的初始化種子。

## 不確定性

| 情況 | 分析單位 | 區間估計 |
| --- | --- | --- |
| 比較兩個設定 | 每個種子一個值，依種子編號配對 | 配對差的 95% 信賴區間，以 t 分布計算 |
| 單一模型的指標 | 回合 | 以回合為群集的自助法，10,000 次重抽，取百分位數區間 |
| 跨種子彙總單一設定 | 每個種子一個值 | 平均值與 t 分布的 95% 信賴區間，並列出每個種子的值 |

同一回合內的步驟彼此相關，不得把步驟當作獨立樣本計算區間。

種子數少時，只報告平均值會隱藏變異。每個設定都列出每個種子的原始值。

## 校準

讀取器、帶例外或帶機率結果的規則、結構化歸因都輸出機率。所有機率輸出都依下表回報校準，理由記錄在 [decisions/0017](../decisions/0017-calibration-of-probability-outputs.md)。

| 指標 | 計算方式 | 角色 |
| --- | --- | --- |
| 負對數似然 | 真實結果的平均負對數機率 | 主要 |
| Brier 分數 | 預測機率向量與真實結果的獨熱向量之間的平均平方差 | 主要 |
| 可靠度圖 | 依最高類別的機率等數量分箱，每箱的平均機率對平均正確率 | 描述 |
| 期望校準誤差 | 同上分箱，各箱平均機率與平均正確率之差的加權平均 | 描述，分箱估計會低估 |
| 機率誤差 | 預測機率與環境的真實機率之間的平均絕對差 | 帶雜訊的變體中使用，不需要分箱 |

- 分箱數在門檻鎖定時寫定。
- 使用原始機率；溫度縮放等事後校準只作為探索性比較。
- 校準不作為任何檢驗的通過條件，與其他次要指標一起回報。
- 不確定性的估計方式與其他指標相同：以回合為群集的自助法。

## 判定

一項確認性的比較，在以下條件同時成立時判定為通過：

- 配對差的 95% 信賴區間不含 0，且方向與事先寫定的方向一致。
- 配對差的平均值超過門檻鎖定紀錄中的門檻。
- 經同一族的多重比較校正後仍然成立。

**多重比較。** 同一階段的確認性比較為一族，以 Holm–Bonferroni 校正單尾配對 t 檢定的 p 值，顯著水準 0.05。

只有五組種子時，小的效果偵測不到。報告中照實說明每項檢驗在試驗變異下能偵測的最小效果。

## 門檻鎖定

1. 完成試驗，整理基準線的結果。
2. 寫一筆新的決策紀錄，標題為「第 N 階段的門檻」，內容包括：每項確認性比較的指標、方向、門檻值、門檻的依據、種子數、資料分割與規模、讀取器的訓練樣本數、規則語言的編碼方式與複雜度上限等所有會影響判定的設定，以及分析程式碼的提交。
3. 提交後，在該提交上建立附註標籤 `prereg/stage-N`（神經網路歸因的檢驗為 `prereg/attribution`）。
4. 之後才開始確認性的執行。每次執行都記錄所依據的標籤。
5. 看到確認性結果後若要修改任何設定，寫一筆新的紀錄，修改後的結果標為探索性。

## 確認性與探索性

- 門檻鎖定紀錄中列出的比較是確認性的，其餘一律是探索性的。
- 探索性結果照常回報，與確認性結果分開，不作為通過與否的依據。
- 負面結果與未通過的檢驗照常回報，不省略。

## 報告

每個階段完成確認性分析後，寫一份階段報告，放在 `docs/reports/`，檔名為 `stage-N.md` 或 `attribution.md`。報告與決策紀錄一樣，完成後不再修改；之後的更正另寫新報告。

報告的結構：

```
# 第 N 階段報告

- 依據的標籤：prereg/stage-N
- 日期：

## 問題
這個階段要回答什麼，對應哪些研究問題。

## 與計畫的偏離
與門檻鎖定紀錄不同的每一件事，以及原因。沒有偏離時寫「無」。

## 執行
每次執行的提交、設定、種子、硬體、執行時間、最高顯示記憶體用量。

## 結果
每項確認性比較：每個種子的值、平均、信賴區間、門檻、判定。

## 探索性結果
與確認性結果分開。

## 結論與下一步
通過與否，以及它解鎖或擋住了哪些檢驗。
```

報告中的每個數字都必須能以報告列出的提交與設定重新產生。
