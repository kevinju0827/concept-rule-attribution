# 比較設定

第四階段比較哪些設定，以及每一組排除了哪一種解釋。

## 單一比較無法回答的問題

「抽出的規則比神經網路推廣得更好」這個結果，至少有四種可能的解釋：規則形式本身帶來好處；多了參數；多了一個元件，兩個元件互補；或者任務本身太簡單，隨便一個模型都做得到。每一種解釋都需要各自的對照組。

## 推廣測試的設定

| 編號 | 設定 | 排除的解釋 |
| --- | --- | --- |
| 1 | 神經網路預測器 | 比較基準 |
| 2 | 抽出的規則，套用到讀出的狀態 | 與 1 比較，檢驗規則形式的效果 |
| 3 | 規則與神經網路結合：抽出的函式涵蓋這一步時用規則，否則用神經網路 | 與 2 比較，檢驗規則涵蓋不足時的退路是否必要 |
| 4a | 同閘控的雙網路：與 3 使用相同的切換條件，但規則的部分換成第二個以相同資料訓練的神經網路 | 與 3 比較，排除「兩個元件加上切換」 |
| 4b | 加倍參數的單一網路：參數量為設定 1 的兩倍 | 與 3 比較，排除「只是多了參數」 |
| 5 | 編碼器固定在隨機初始化、其餘照常訓練 | 排除「任務太簡單」 |
| 6 | 抽出的規則，套用到真實狀態 | 上限：分辨偏離訓練分布時失敗出在讀取還是規則 |

對照組的設計理由記錄在 [decisions/0015](../decisions/0015-generalization-tests-with-mechanism-composition.md)。

設定 4a 與 4b 是時間不夠時最容易被省略的兩組，也是事後最難自圓其說的兩組。少了它們，任何勝出都留著無法排除的替代解釋。

所有設定的預測都以同一組讀取器讀成 `State`，在同一個空間中與真實的下一步比較。設定 1、3、4a、4b、5 中神經網路的預測，依 [readout.md](readout.md) 的方式讀取；設定 2、3 的規則部分，輸入為以同一組讀取器讀出的狀態。

這些設定用於 4.1 分級推廣與 4.4 機制組合。4.4 中，每個設定都在機制組合條件的資料上重新訓練或抽取；主要條件中以 `full` 訓練的同一設定，在相同的測試資料上評估，作為「看過這些組合」的參考，比較的對象是兩者之差，也就是組合代價。

4.5 帶雜訊的世界不比較這些設定：神經網路只給出單一預測，規則給出機率分布，兩者的推廣表現沒有共同的量尺。4.5 只與未經訓練的模型與真實規則比較。

## 歸因比對的設定

| 估計 | 來源 |
| --- | --- |
| 神經網路歸因（純量） | 轉移頭在實際動作與「什麼都不做」下的兩個預測之差異量 |
| 神經網路歸因（結構化） | 上述兩個預測各自讀成 `State` 後的差異 |
| 規則歸因 | 狀態轉移函式在實際動作與「什麼都不做」下的兩個模擬結果之差 |
| 規則歸因（真實狀態） | 同上，但從真實狀態出發；讀取不出錯時的上限 |
| 標準答案 | 複製環境後兩個分支的真實狀態之差 |
| 基準：未經訓練的模型 | 以相同架構、未經訓練的模型計算的神經網路歸因 |
| 基準：觀測變化量 | 相鄰兩步表示的距離，不做反事實 |

各估計的定義與指標見 [attribution.md](attribution.md)。

## 不算勝出的情況

一個設定只有在門檻鎖定紀錄事先寫定的條件下、使用相同的讀取方式與相同的測試資料勝過比較對象，才算勝出。看到結果後才選出的條件、只有某一個設定能被評分的檢查，都不算。
