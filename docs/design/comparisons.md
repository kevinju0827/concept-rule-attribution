# 比較設定

第四階段比較哪些設定，以及每一組排除了哪一種解釋。

## 單一比較無法回答的問題

「抽出的規則比神經網路推廣得更好」這個結果，至少有三種可能的解釋：規則形式本身帶來好處；多了一個元件，等於多了參數與計算；或者任務本身太簡單，隨便一個模型都做得到。每一種解釋都需要各自的對照組。

## 推廣測試的設定

| 編號 | 設定 | 排除的解釋 |
| --- | --- | --- |
| 1 | 神經網路預測器 | 比較基準 |
| 2 | 抽出的規則 | 與 1 比較，檢驗規則形式的效果 |
| 3 | 規則與神經網路結合：規則能解釋時用規則，否則用神經網路 | 與 2 比較，檢驗規則涵蓋不足時的退路是否必要 |
| 4 | 容量相當的較大神經網路，參數量對齊 3 | 與 3 比較，排除「只是多了參數與計算」 |
| 5 | 相同架構、未經訓練的隨機編碼器 | 排除「任務太簡單」，作為所有門檻的基準線 |

設定 4 是時間不夠時最容易被省略的一組，也是事後最難自圓其說的一組。少了它，任何勝出都留著一個無法排除的替代解釋。

## 歸因比對的設定

| 估計 | 來源 |
| --- | --- |
| 神經網路歸因 | 預測器在實際動作與「什麼都不做」下的兩個預測之差 |
| 規則歸因 | 狀態轉移函式在實際動作與「什麼都不做」下的兩個模擬結果之差 |
| 標準答案 | 複製環境後兩個分支的真實狀態之差 |
| 基準線 | 以隨機編碼器計算的神經網路歸因 |

## 不算勝出的情況

一個設定只有在 [evaluation.md](evaluation.md) 事先寫定的條件下、使用相同的讀取方式與相同的測試資料勝過比較對象，才算勝出。看到結果後才選出的條件、只有某一個設定能被評分的檢查，都不算。
